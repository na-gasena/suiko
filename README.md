# 推敲の跡

俳人がひとつの文章を推敲する時間を見せる、パフォーマンス用Webアプリのプロトタイプです。

## GitHub Pages

公開URL: https://na-gasena.github.io/suiko/

`npm ci`、`npm run build:pages` で静的サイトを `out/` に生成します。`npm run preview:pages` でその出力を確認できます。GitHub の Settings → Pages で Source を GitHub Actions にすると、`main` への push で自動公開します。

Pages版はサーバーやSitesへの接続を使わず、ブラウザ内だけで動作します。相対パスで配信するため、リポジトリ名のサブディレクトリにも対応します。履歴は利用者のブラウザ内に保存され、公開リポジトリには入りません。

## 使い方

1. 紙面をクリックして直接入力すると、その回の時計が始まります。
2. 確定した文字を消すと、元の位置に薄い消し跡が残ります。跡は薄くなっても消えきらず、重ねて消すほど濃くなります。濃さには上限があります。
3. HDMI接続したディスプレイをOSの設定で「拡張表示」にします。「別ウィンドウ」を押すと専用ウィンドウが開くので、HDMI側へ移動し、ダブルクリックまたはFキーで全画面表示にします。編集画面は手元のディスプレイに残してください。ブラウザ設定によってタブで開く場合は、タブを別ウィンドウに切り離して移動します。
4. 一時停止ボタンで入力と推敲時間を止め、再開ボタンで続けます。1時間で自動終了はしません。
5. 「新しく書く」で古い紙面を履歴に残し、新しい紙を始めます。
6. 「履歴」で各回の紙面と操作履歴を確認できます。「CSV出力」は全履歴、履歴内のボタンは各回を出力します。

別ウィンドウには文章と消し跡だけを描画します。紙番号・飾り線・休憩ラベル・操作ボタン・接続メッセージ・マウスポインターは表示しません。接続前は白紙、接続が途切れた場合は最後の紙面を残します。接続状況と全画面のエラーは演者側に表示します。全画面を解除するときはEscまたはFキーです。ブラウザが一時的に出す全画面の案内やOS通知はアプリ側から消せないため、上演前に全画面へ切り替え、OSの通知をオフにしてください。

履歴は「01」「02」の番号で表示します。各番号の「×」で、その回の文章・消し跡・入力記録を削除します。画面を再読み込みするまでは「削除を取り消す」で順に戻せます。編集中の回を閉じると、次の番号の空欄が開きます。削除した回はCSV出力にも含まれません。

## 保存とCSV

- 文章・消し跡・入力イベントは端末のIndexedDBへ保存します。設定はlocalStorageへ保存します。サーバーには上演内容を送信しません。
- 同じURL・同じブラウザの再読み込みで復元します。別ブラウザや別URL（ローカルから公開URLなど）には自動で移りません。
- ブラウザのサイトデータを削除すると履歴も消えます。上演後はCSVを保存してください。CSVの再取込・紙面の完全再生はこの版には含みません。
- 保存エラーは画面に表示します。未保存のイベントも、画面を開いている間はCSVに含めます。
- CSVはUTF-8 BOMつき、CRLF区切り、全セル引用符つき。日本語・改行・引用符を保持します。表計算ソフトで数式として扱われる可能性がある文字列には先頭に `'` を付けます（解析時には必要に応じて除去してください）。
- `timestamp_utc` はISO日時、`elapsed_ms` は開始からの実時間（休憩を含む）、`active_ms` は休憩を除いた推敲時間です。画面を閉じても「推敲中」の時計は進む扱いです。
- `start_utf16` はJavaScript文字列と同じUTF-16位置。差分は絵文字・結合文字を途中で切りません。
- 履歴とCSVには、入力・削除・置換など、確定した変更だけを記録します。変換途中・変換終了・開始イベントは表示・出力しません。
- `composition_id` は一連の日本語入力の識別子。設定変更も `settings_json` に保存します。

## 文字の動き

設定は通常の作業面から隠しています。作業面下の設定ボタンから必要なときだけ開けます。初期設定は「虫のように」です。地と文字の反転、フォント、文字詰め、行詰めを選べます。消しゴムでは薄くなる時間と消し跡の濃さ、虫と風ではそれぞれの動きのパラメータだけを表示します。

- 「虫のように」: 消した文字が一文字ずつ方向を変え、速度を変えながら紙面を這います。紙の端では折り返します。
- 「風に漂う」: 風・抵抗・浮力をイメージした軌道で、回転しながら浮き上がります。厳密な物理シミュレーションではありません。
- どちらも「薄くなる時間」を過ぎると動く文字は消え、元の位置には静かな消し跡が残ります。現在の確定文は動かしません。
- 位置は文字IDと削除からの実時間で決まるので、演者画面と投影画面で同じ動きになります。
- OSで「動きを減らす」が指定されている場合は、その端末では消しゴム表現に切り替えます。
- 追加前の消しゴム版はGitタグ `eraser-before-motion` に保存しています。公開URLの元の版も保持しています。

## 日本語入力

編集面ではブラウザ標準の日本語入力・選択・カーソルを使います。別ウィンドウの変換途中は薄い文字で表示し、候補切り替えの残像は約2秒で消えます。確定後に削除した文字だけが永続的な消し跡になります。「変換途中も跡に残す」で途中の文字も画面上に蓄積できます。変換途中のイベントは履歴・CSVには保存しません。未確定文字は再読込時には復元せず、確定文を復元します。

取得できる変換途中のイベントはOS・ブラウザ・IMEに依存します。変換候補一覧全体の取得はしません。実機での日本語IME検証は別途必要です。IME変換中はセッション切り替えと設定変更を無効にします。

## 範囲

- 1文あたり最大2,000 UTF-16単位。長文では紙が縦に伸びます。
- 同じPC・同じブラウザのタブ間をBroadcastChannelで同期します。インターネット越しのライブ共有は未実装です。
- 編集画面はWeb Locksで1つに制限し、二重編集による履歴の衝突を防ぎます。最新版のChrome / Edge等の対応ブラウザを利用してください。
- 描画は960px幅の共通座標で行い、別ウィンドウでも同じ位置に消し跡を表示します。入力欄と同じフォント・行間・折り返しをDOMで計測し、投影と消し跡にも使います。禁則処理は行わず文字単位で折り返します。
- 個人用のプロトタイプ公開にSitesを利用します。有料の外部DBやAPIは使用していません。一般公開や別端末への同時配信は次の段階で扱います。

## 開発

Node.js 22.13以降。`npm install`、`npm run dev` で開発、`npm run build` でビルドします。

検証: `npm run lint`、`npx tsc --noEmit`、`node --experimental-strip-types --test tests/*.test.mjs`。既存の生成済みUIライブラリはlintの対象外です。DOMシミュレーションの統合テストは、実際のブラウザ・IMEによる検証を代替しません。

実機で確認する項目: ひらがな入力→漢字変換→候補切替→確定、Esc取消、選択範囲の再変換、全文削除、Ctrl+Z/やり直し、貼り付け、休憩中の再読込、別ウィンドウの同期。
