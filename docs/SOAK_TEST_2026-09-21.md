# 長時間推敲の同期試験（2026-09-21）

## 目的

同じ文章を繰り返し消して書き直したとき、編集画面では書けるのに表示画面だけ更新されなくなる症状が、40分程度の使用で再発しないか確認する。

## 構成

- 編集画面: 公開中の GitHub Pages と同じビルドを `localhost:4173` でプレビュー。
- 表示画面: 公開中の `https://na-gasena.github.io/suiko/` を別タブで開く。
- 同期経路: 両画面とも公開中の Cloudflare Worker / Durable Object に WebSocket 接続。オリジンが異なるため、同一オリジンの BroadcastChannel では表示を同期できない構成。
- テスト専用の新規ルームを使用。既存の上演データは使っていない。

## 操作と結果

- 同じ編集セッションを **42分28秒** 維持し、1行の文章を繰り返し1文字へ置換してから全文へ戻した。新しい文章への切り替えはしていない。
- 各変更後に編集欄の実際の値と表示画面の canvas の文字列を照合した。消し跡が約1,500文字を越えた後も照合は一致した。
- 最終時点の消し跡は **2,384文字分**。オンライン画面の表示接続数は **1**。
- 40分経過後に日本語の1行「春の雨に濡れた犬が橋を渡っていく」へ変更し、さらに1文字への置換と再入力を行った。いずれも表示画面に反映された。
- 編集画面だけ更新され、表示画面が古い文章のまま止まる症状は再現しなかった。

試験用ブラウザの自動入力には、空文字への `fill` が消去として反映されない事例と、日本語IMEが意図しない文字を挿入する事例があった。このため、途中から非空文字への置換を使用し、「指定したテスト文字列」と「編集欄の実際の値」を分けて確認した。これらの事例でも表示画面は編集欄の実際の値に追随しており、同期停止とは判定していない。

## この試験の範囲

編集と表示は同じPC上の別オリジンのブラウザタブで確認した。別の物理端末、Wi-Fi切断からの復帰、表示端末を複数台つないだ状態、1時間連続上演は今回の試験に含まない。編集画面のローカルプレビュービルドは公開版と同じバンドルを使用した。
